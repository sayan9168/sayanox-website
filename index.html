Why Sayanox?

Most new languages are either too academic or thin wrappers around existing runtimes. Sayanox aims for a clean middle ground.

🔁

Self-Hosting

The compiler is written in Sayanox itself. Pure-min dialect: seed → gen1 → gen2 → gen3, byte-identical.

⚡

Native AOT

Native ahead-of-time compilation for x86-64 Linux. Also emits i386, aarch64 and riscv64 ELF.

📦

Offline Packages

Full package tool (sxpkg) written in Sayanox — digests, HMAC signatures, public-key verification.

🛠

Tools in Sayanox

Formatter, package manager, language server (LSP) — all maintained in Sayanox.

📐

Readable Syntax

hold / show, when / otherwise, make / give. Designed to be easy to read and write.

🇮🇳

Made in India

One of the few original systems programming languages being built from India with a strong self-hosting focus.

Syntax at a Glance

Clean, minimal, powerful. Source files use the .sa extension.

Bindings & Output
hold value = 42
hold name = "Sayan"
show value
show "text"
show value + 1
Functions
make square(x) {
  give x * x
}
show square(8)
Conditions & Loops
when condition {
  show "yes"
} otherwise {
  show "no"
}
while condition {
  show "loop"
}
Lists & Structs
hold values = [1, 2, 3]
hold p = {x: 10, xs: values}
for v in p.xs {
  show v
}

Full syntax reference, type system, modules, generics and status tables live in the official docs.

Get Started

1

Clone the repository

git clone https://github.com/sayan9168/sayanox.git
cd sayanox
2

Verify entry & bootstrap

sha256sum -c bootstrap/sx.sha256
./sx doctor
./sx target gen2
3

Compile & run a program

./sx target native
./selfhost/native_aot examples/hello.sa hello
./hello

Full build instructions, status tables and migration notes are in the README.
